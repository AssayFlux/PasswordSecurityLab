# Security Policy

APSL is educational research software, not a production authentication system.

- Use only synthetic passwords, hashes, and datasets you own or are authorized to test.
- No online account attacks, credential stuffing, login automation, session extraction, phishing, or credential collection.
- Never commit or log plaintext passwords, tokens, or private datasets.
- Lab simulations must remain local, explicitly scoped, bounded, and cancellable.
- Treat benchmark output as specific to the tested device and configuration.

Report suspected vulnerabilities privately to the repository maintainer with a minimal reproduction using synthetic data. Never include real credentials or personal data.
